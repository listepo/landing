cox.

A modular terminal coding agent in Rust. Named for the coxswain: it steers the work while models, tools and extensions row — one reliable, testable agent core with several ways to use it.

One core, many surfaces

Built on four design principles.

  • Interactive TUI

    Enter sends, Esc interrupts; y/s/n answer approval prompts, /model switches tiers, /compact compacts now.

  • Headless automation

    cox run -p drives headless scripts from the same agent core.

  • Editors & other agents

    cox acp serves Zed and JetBrains through ACP, and MCP tools are exposed for other agents.

  • One event stream

    Submissions enter a pure core state machine and typed events leave it. Every surface consumes the same events.

  • Safe by default

    Permission decisions are centralized, model paths stay inside the workspace, and shell commands run in a sandbox unless you choose otherwise.

  • Lossless context, visible costs

    Full tool output is archived before shortening and stays retrievable by ID. Provider usage is recorded per request; costs land in cox stats.

Get started

Build it and run your first task.

Clone and build

Rust is pinned through mise; run Cargo through mise rather than a global toolchain.

$ git clone https://github.com/pyrlyn/cox && cd cox
$ mise exec -- cargo build -p cox

Check and run

Set a provider key, check your setup, then run headless or open the TUI.

$ export ANTHROPIC_API_KEY=sk-...  # or OPENAI_API_KEY
$ ./target/debug/cox doctor
$ ./target/debug/cox run -p "create hello.txt containing hi"

Status from the README: cox is under active development. APIs, configuration and installation instructions are not yet stable.
