FAQ

Questions, answered.

Do I need an app to use Tempo Dial?

No. Twist to set, press to start. The optional companion app only adds do-not-disturb sync and history export.

How long does the battery last?

Around six weeks with four sessions a day. It charges fully in about 90 minutes over USB-C.

Does it make any sound?

By default it is silent and uses light plus a gentle haptic pulse. A soft chime can be enabled.

What if it is not for me?

Send it back within 60 days for a full refund. We cover return shipping.
