ketch.

Catch releases straight from GitHub. Install command-line tools and apps from GitHub releases — no taps, no formulae, no build step. ketch downloads what a project already ships, verifies it, and puts it on your PATH.

View on GitHub Install Documentation
ketch install
$ ketch install BurntSushi/ripgrep  # any repo that publishes releases
$ ketch install rg  # or a name ketch already knows
$ ketch install sharkdp/fd@v10.2.0  # or an exact version
$ ketch install --path ./mytool  # a local binary, archive, symlink, or .app

Why ketch

The artefact is already there.

  • Any repo that ships releases

    No formula, no tap, no waiting for a maintainer. Point it at owner/repo.

  • Verified, not just downloaded

    Published SHA-256 sums are checked against what landed on disk; require_checksums refuses anything that publishes none.

  • Apps as well as binaries

    An .app bundle goes to /Applications, quarantine cleared when the signature checks out, removed cleanly on uninstall.

  • One tree

    Everything under ~/.ketch. Uninstalling leaves nothing behind.

  • Rollback & history

    Upgrades keep the previous version; ketch rollback relinks it without re-downloading, and ketch history remembers what you had.

  • Reproduce a machine

    ketch lock writes ketch.lock; ketch sync makes a new machine match it.

Get started

Install ketch, then catch anything.

macOS & Linux

$ curl -fsSL https://raw.githubusercontent.com/pyrlyn/ketch/main/install.sh | bash

Windows

$ irm https://raw.githubusercontent.com/pyrlyn/ketch/main/install.ps1 | iex

Homebrew or mise

$ brew install --cask pyrlyn/tap/ketch
$ mise use -g github:listepo/ketch
$ ketch path install

Everyday use

$ ketch list  # what is installed
$ ketch outdated  # what has a newer release
$ ketch upgrade  # bring everything unpinned up to date
$ ketch doctor  # check the environment

Make sure ~/.ketch/bin is on your PATH — ketch doctor will tell you if it is not.

Reference

Commands you will use.

CommandWhat it does
ketch install <pkg>...install; concurrent by default, --jobs N to change
ketch rollback <pkg>restore the previous retained version
ketch info <pkg>details, including --assets and why each scored
ketch search <query>the registry and GitHub
ketch changelog <pkg>what changed: the shipped file, or the release notes
ketch pin / unpin <pkg>hold a version, or let go
ketch lock / syncwrite ketch.lock, or install what it names
ketch self upgradeupgrade ketch itself
