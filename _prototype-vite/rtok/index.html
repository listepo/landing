Why rtok

Ten methods, one process, one ledger.

  • Three surfaces, one binary

    Claude Code hooks, an MCP server and an API proxy ship in a single Rust binary.

  • Measured, not claimed

    A saving that is not a row in the ledger does not exist — including rtok’s own. Provider-reported usage is ground truth.

  • Lossless by design

    Archive and proxy reductions keep the original: rtok expand <id> retrieves the full payload, a line range or grep matches.

  • Fails open

    Hooks that hit an error return the unmodified input and exit successfully.

  • Code graph over MCP

    rtok graph index . builds a symbol index the agent queries as symbol, callers, impact, outline and explore.

  • Plugins & OpenTelemetry

    measure, cmd, read, archive, proxy, inject, guard, memory, graph and toon — each can be toggled; calls export to Jaeger, Grafana, SigNoz or Maple.

Get started

Install, then wire up Claude Code.

Installer script

macOS (Apple silicon or Intel) and Linux x86-64. Puts rtok in ~/.cargo/bin.

$ curl --proto '=https' --tlsv1.2 -LsSf https://github.com/pyrlyn/rtok/releases/latest/download/rtok-installer.sh | sh

Or with ketch, Homebrew, npm or PyPI

$ ketch install pyrlyn/rtok
$ brew install pyrlyn/tap/rtok
$ npm i -g rtok-cli
$ uv tool install rtok-cli

Start with Claude Code

Installs rtok’s eight hooks and MCP entry. Settings are backed up first; --dry-run touches nothing.

$ rtok agents install claude --dry-run
$ rtok agents install claude
$ rtok doctor

Run a command without paying for its output

Output is archived to ~/.rtok/archive/<id>; the original is one command away.

$ rtok run -- cargo test
[rtok 7f3a91 · 412 lines · expand: rtok expand 7f3a91]
$ rtok expand 7f3a91 --grep "panicked"

Honest status from the README: estimates are a chars-per-token heuristic until matched with provider usage, and no live A/B cost reduction has been established yet.
